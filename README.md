# Employee Attrition Prediction System

## Project Overview
Developed a Machine Learning-based classification system to predict whether an employee is likely to leave or stay in an organization based on various HR-related factors.

The project aims to help organizations identify potential employee attrition and support better workforce planning.

## Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- XGBoost
- Streamlit
- Joblib

## Key Features
- Data preprocessing and cleaning.
- Exploratory Data Analysis (EDA).
- Handling numerical and categorical features.
- Feature engineering and selection.
- Classification-based predictive modeling.
- Model preprocessing and serialization.
- Interactive Streamlit prediction interface.

## Key Factors Considered
- Age and Job Role
- Monthly Income
- Job Satisfaction
- Environment Satisfaction
- Work-Life Balance
- Overtime
- Years at Company
- Total Working Experience
- Performance-related factors

## Project Workflow
1. Data collection and preprocessing.
2. Exploratory Data Analysis.
3. Feature engineering and selection.
4. Model training and evaluation.
5. Employee attrition prediction.
6. Streamlit application deployment.
